## エリア別候補地

### 宇野港周辺
*コンセプト：直島フェリー客流・アート路線・海望キャンプ*

#### エリア概況
宇野港はJR宇野駅から徒歩3分の立地で、直島・豊島・小豆島へのフェリー乗り場に隣接する国際観光拠点。年間訪問客の多くが直島行きフェリーを待つ時間を利用しており、キャンプ・グランピング需要は高い。

#### 参考：既存キャンプ施設
**瀬戸内温泉たまの湯キャンプ場**（運営中施設として参考）

| 項目 | 詳細 |
|------|------|
| **所在地** | 岡山県玉野市（宇野港近傍） |
| **特徴** | 宇野港が見える・瀬戸内海望・温泉施設隣接 |
| **アクセス** | JR宇野駅徒歩圏 |
| **直島連動** | フェリー待ちキャンプ需要・直島/豊島/小豆島アクセス |
| **競合注意点** | 既存施設あり。差別化（グランピング・アート連動）要検討 |

[施設参考URL](https://www.nap-camp.com/okayama/14165)

#### 地価動向（2025年）
- 宇野エリア住宅地路線価：**平均11.6万円/坪**（前年比微減）
- 大規模山林・原野は流通少なく、個別交渉が基本

---

### 渋川海岸
*コンセプト：海辺キャンプ・ファミリー向け・直島連動*

#### エリア概況
渋川海岸は「日本の渚100選」「日本の快水浴場100選」に選定された約1kmの白砂青松の海岸。ファミリー向けビーチキャンプの高ポテンシャルエリア。

#### 土地市場情報（2025年）
| 項目 | 詳細 |
|------|------|
| **住宅地地価（渋川）** | 坪単価 **6.5万円/坪**（2.0万円/㎡） |
| **前年比** | -3.0%（下落トレンド） |
| **500坪目安価格** | 約3,250万円（参考値） |
| **ビーチ環境** | 白砂・松林・瀬戸内海望 |
| **2026年シーズン** | 海水浴7/11〜8/23、SUP・イベント予定 |

#### 開発適性評価
- **強み**：日本一のビーチブランド、訪日外国人需要、直島連動
- **課題**：自然公園・砂防法規制確認必須、大規模用地の流通量少
- **推奨行動**：玉野市役所建設部門への問い合わせ、地元不動産業者への個別照会

---

### 王子が岳
*コンセプト：パノラマ海景・高単価グランピング・絶景サイト*

#### エリア概況
王子ヶ岳（倉敷市・玉野市境）は奇岩・ブルダリングの聖地として知られ、山頂からの360度パノラマ瀬戸内海景は西日本屈指の絶景。高単価グランピング適地として注目度上昇中。

#### 参考：既存グランピング施設
**Whale Island（ホエールアイランド）グランピング**（運営中施設として参考）

| 項目 | 詳細 |
|------|------|
| **所在地** | 王子ヶ岳麓の無人島（クジラ島） |
| **収容** | 2〜52名対応 |
| **スタイル** | 設備付きテント・グランピング形式 |
| **競合注意点** | 既存施設あり。本島側山林での差別化プレミアムサイト検討可 |

#### 開発適性評価
- **強み**：瀬戸内随一の絶景、高単価ターゲット（外国人・富裕層）、SNS映え
- **課題**：急峻地形、アクセス道路（幅員・傾斜）確認必須、山林規制
- **推奨行動**：倉敷市・玉野市農林水産部門への山林転用相談
